Unachopata kwenye akaunti yako

Kila kitu cha kusimamia ufikiaji wako wa API kiko mahali pamoja.

API Key binafsi

Key yako ni yako peke yako. Unaweza kuibadilisha au kuifuta wakati wowote.

Endpoint kwa kila channel

Kila channel ina jina na namba yake, na kuna endpoint moja ya kupata zote kwa pamoja.

Malipo ya simu

Unapokea ombi la PIN kwenye simu. Malipo yakithibitishwa, key yako inawaka mara moja.

Vifurushi vya muda

Siku, wiki au mwezi. Ukilipia kabla kifurushi hakijaisha, muda unaongezwa.

Historia ya matumizi

Ona kila ombi la API: lililofanikiwa, lililoshindwa, na saa lilipofanyika.

Inafanyaje kazi

Hatua nne kutoka kujisajili hadi kupata data.

1

Jisajili

Jina, namba ya simu na password. Unapata API Key yako.

2

Chagua kifurushi

Angalia bei na muda wa kila kifurushi kwenye dashboard.

3

Lipia kwa simu

Thibitisha kwa PIN. Malipo yakikamilika, key inawaka.

4

Tumia API

Tuma X-API-Key kwenye GET /api/v1/amiri/{jina}.
