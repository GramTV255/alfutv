Muhtasari

API Key binafsi

Kila mtumiaji ana key yake. Inatumwa kwenye header, si kwenye URL.

Endpoint kwa kila source

Kila source ina jina (slug) na ID yake, kwa hivyo zinatofautiana.

Data mpya

Seva inasasisha vyanzo kila dakika chache, kwa hivyo token na ClearKey ni mpya.

Mifano yote hapa ni ya kubuni — si token halisi.

Authentication

Tuma API Key yako kwenye HTTP header X-API-Key. Usiiweke kwenye URL.

X-API-Key: YOUR_PERSONAL_API_KEY

Pata key yako kwenye Dashboard → API Key. Key kamili inaonyeshwa mara moja tu; seva inahifadhi hash yake.

Endpoints

Base URL: https://your-domain.example/api/v1 (tumia HTTPS pekee).

GET/api/v1/amiri/{jina}

Channel moja kwa jina lake (mfano azam-sports-1). Kila channel ina endpoint yake; hakuna endpoint ya kupata zote kwa pamoja. Inarudisha mpd_url yenye token mpya, pamoja na ClearKey. Majina ya channels zako yanaonekana kwenye Dashboard.

SehemuMaelezo
Header (lazima)X-API-Key
Query (hiari)format=text — majibu kama mistari ya maandishi badala ya JSON

Seva inakagua: key ni halali, akaunti haijasimamishwa, kifurushi ni ACTIVE na hakijaisha, channel inatumika, na token ni mpya (inachukuliwa kila ombi).

Channels

Orodha ya endpoint za channels zinazopatikana sasa.

Ingia ili uone orodha ya channels zako, au angalia Dashboard.

Response

Mafanikio: 200 OK, application/json.

{
  "channel": "Channel Name",
  "id": 1,
  "slug": "channel-name",
  "mpd_url": "https://example.com/.../manifest.mpd?token=EXAMPLE",
  "token": "EXAMPLE_TOKEN",
  "clearkey": "KID_HEX:KEY_HEX",
  "clearkeys": { "KID_HEX": "KEY_HEX" },
  "expires_at": "2026-01-01T12:00:00.000Z"
}
FieldMaana
mpd_urlLink ya MPD ya kucheza
tokenToken iliyomo kwenye link
clearkeyClearKey ya kwanza, kid:key
clearkeysFunguo zote kama { kid: key } (Shaka / ExoPlayer)
expires_atMuda ambao token inaisha

Majibu hayahifadhiwi kwenye cache (Cache-Control: no-store).

Mipaka & Kifurushi

Kila key ina kikomo cha maombi kwa dakika. Ukivuka unapata 429. Key inafanya kazi tu wakati kifurushi chako ni ACTIVE; kikiisha, key inakuwa INACTIVE hadi ulipie tena.

Tumia data hii kwa vyanzo na maudhui ulivyoidhinishwa kutumia pekee.
